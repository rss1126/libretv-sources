# LibreTV 可用源订阅（39 个点播 + 8 个直播）

2026-11-21 本机逐条实测整理的 LibreTV 点播源与直播源订阅文件，点播侧覆盖**短剧、电影、电视剧、动漫、综艺、体育**。所有源均验证过 `?ac=list` 返回正常 JSON 且带分类表，剔除全部失效与纯非正片源。

## 怎么用

在 LibreTV 里打开 **设置 → 源管理 → 数据源订阅**，粘贴下面任意一条：

**全量版（推荐，立即生效，绑定提交 sha）**

```
https://cdn.jsdelivr.net/gh/rss1126/libretv-sources@fa4eb6c/libretv-sources.json
```

**跟随 main 长期版**（jsDelivr 对分支有约 12 小时缓存，仓库更新后不会立刻变）

```
https://cdn.jsdelivr.net/gh/rss1126/libretv-sources@main/libretv-sources.json
```

导入后 39 个点播源与 8 个直播源一次性进库，无需手工逐条添加。想只留一部分，在源管理里按下面「按用途选源」的建议勾选即可。

> 不能直接用 GitHub raw 地址（`raw.githubusercontent.com` 在国内多数网络下不可达），必须走 jsDelivr 镜像。

## 实测方法与判定标准

- 点播：对每个候选请求 `?ac=list`，25 秒超时，判定为通过的条件是返回 JSON 且 `list` 非空、能取到 `class.type_name`；延迟取该次请求的实际耗时。
- 直播：解析 m3u 内 `#EXTINF` 计频道数，随机抽 4–6 条流验证首包返回 `#EXTM3U`。
- 三轮累计测了 100 余条候选，通过 39 个点播源。域名不解析、20 秒无响应、返回非 CMS 结构的全部剔除。

## 说明

- 采集站换域名是常态，源失效后在源管理里点「批量测活」，连续失败的不勾选即可，LibreTV 会按阶梯时长自动停用。
- 本仓库只做可用性实测与整理，不含任何影视文件，也不代理、不存储内容。所有接口均由第三方站点提供，清晰度与稳定性受其自身影响。
- 部分采集站带非正片子分类，介意的话按「按用途选源」里推荐的干净源使用。
- 看剧请支持正版。
